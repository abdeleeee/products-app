## 📌 Objectif

Cette activité a pour objectif de mettre en œuvre la couche de persistance d'une application Spring Boot en utilisant :

- Spring Data JPA
- Hibernate ORM
- Base de données H2
- Lombok

L'application permet d'effectuer les opérations CRUD sur l'entité `Product`.

---

## 🛠 Technologies utilisées

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
